# Packaged reference voices

`soft-young-indonesian-woman.reference.wav` is the reference the Chatterbox engine clones when the
"Soft Young Indonesian Woman" designed voice is used. It is entirely synthetic and belongs to no
real person: Chatterbox-TTS-Indonesian's own default voice (Apache-2.0) reading a neutral passage
(`pipeline.SYNTH_PASSAGE`), reshaped by NOVA's WORLD conversion to the preset (228 Hz, vocal tract
1440 Hz, breathiness 0.32). Shipping it keeps the voice identical on every computer and every day.
It was not made from any recording of a real speaker, including any ElevenLabs voice.
