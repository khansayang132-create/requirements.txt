# AURAVOX X

Everything runs through the `avx` CLI (package in `auravox/src/auravox`). Install once:

```bash
cd auravox && uv venv .venv && uv pip install -e ".[piper,test]"     # or: python -m venv .venv && pip install -e ".[piper,test]"
export AVX_HOME=$PWD/data                                            # database, takes, productions, reports
```

## Pipeline

REQUEST → PLAN → DISCOVER → INSTALL → CONFIGURE → GENERATE → EVALUATE → REFINE → EXPORT → VERIFY

| Step | Command | Evidence it leaves |
|---|---|---|
| Discover | `avx doctor` | `reports/environment.md`, `engines.md`, `technology-registry.md`; engine health from real speech |
| Install | `avx models install KEY [--approve]` | MD5-checked file, sha256, licence from the model card; over `AVX_MAX_MODEL_MB` (200) needs `--approve` |
| Configure voices | `avx voices from-humanverse CAST_DIR`, `audition VID`, `select-cast`, `approve VID TAKE --by NAME` | approved profile hash; later drift raises `VoiceLocked` |
| Plan | `avx produce SCREENPLAY --name NAME` | job graph AVX-JOB-*: lines → assemble → master + lip-sync report |
| Generate / evaluate / refine | `avx work` | takes with metrics and defects; rejected takes kept; corrective regenerations within the retry limit |
| Export | files under `productions/NAME/` | `dialogue.wav/json/srt`, stems, `master.wav/mp3`, `master_report.json`, `lipsync_report.json` |
| Hand off | `avx humanverse-export NAME HV_PROJECT` | HUMANVERSE `audio/lines/lines.json` with phoneme timings |
| Verify | `avx queue`, `avx serve` (control centre), `pytest` | job states, events, measured reports |

Screenplay text format: `# SCENE S01` lines, then `NAME (emotion): text`, with `*word*` for emphasis. Emotions:
neutral, happy, excited, laughing, sad, crying, worried, angry, surprised, calm, whisper.

## Hard rules

- Status is PASS, FAIL, BLOCKED or NOT TESTED, with evidence. An engine counts only after it spoke and was measured.
- Never substitute another engine or language silently: a line whose voice engine is not PASS is BLOCKED.
- Never change an approved voice silently (`avx voices redesign VID --by NAME --reason TEXT` is the only way).
- Never clone a real person's voice without their written authorisation; never mark a voice commercially usable
  unless the model licence allows it.
- Never install a skill over another without `--replace` (backed up first, `avx skills rollback` restores it).
- The queue survives crashes: re-run `avx work`; expired leases are recovered.

## Agents

21 agents, one per job (orchestrator, voice designer, mix engineer, release verifier, ...), are generated by
`tools/gen_agents.py` for both hosts: Claude Code subagents in `.claude/agents/avx-*.md`, Codex agents in
`.codex/agents/avx-*.toml`. Edit the generator, then re-run it.

## Gates (see `docs/milestones.md` for the evidence)

1. Working local engine. 2. Three distinct voices and a full conversation. 3. Queue, evaluation, retry and resume
after restart. 4. Blender lip-synced dialogue exported to a playable MP4 (`demo/gate4/gate4.py`).
