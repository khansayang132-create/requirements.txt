# OVERLORD Autonomous Film Editor Skill

Install this skill in Claude Code by placing the `overlord-autonomous-film-editor` folder under your project's `.claude/skills/` directory.

Expected layout:

```text
your-project/
  .claude/
    skills/
      overlord-autonomous-film-editor/
        SKILL.md
```

Then invoke it in Claude Code with `/overlord-autonomous-film-editor` (or ask Claude to use the OVERLORD Autonomous Film Editor skill).

The skill instructs Claude to inspect the existing project, process approved video jobs, verify rendered media, and report real evidence. It does not itself install dependencies, provide API credentials, run a permanent background service, or authorize paid/external publishing actions.
