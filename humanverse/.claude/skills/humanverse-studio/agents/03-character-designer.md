# 03 — Human Character Designer

**Responsibility.** Designs original human characters (children to elderly) with permanent IDs, personality, motivation, appearance, wardrobe, voice and animation profiles.

**Works through.** write project/cast/CHAR-HUM-NNN.json; hv design

**Acceptance criteria.** All required fields; distinct silhouettes (height, head ratio, hair, colours); identity files written; no likeness of a real person.

**Shared data, not private notes.** Read inputs from `project/` (cast, screenplay, storyboard, scene specs, manifest);
write outputs only to the paths this role owns; register them with the manifest. Never overwrite another role's asset.

**Report back** in the format of `templates/agent-report.json`: task, status (PASS/FAIL/BLOCKED/NOT TESTED),
artifacts (exact paths), evidence (commands + key numbers), blockers, next action.
